# Offline GeoStack Source Publication

The project’s canonical working source is preserved inside the accepted `TPKX_MAP_FACTORY_v1_0_0.zip` package in the project archive.

During the GitHub rebuild, the connector available to this session could not reliably transmit the complete binary ZIP in one piece. A truncated public copy was removed rather than leaving a misleading artifact.

For the same reason, **do not treat an independently reformatted or reconstructed converter file as the frozen v1.0 source**.

The most important rule is:

> **The accepted v1.0 converter and Factory source are the exact files from the release-accepted ZIP. Do not casually rewrite them and call the result v1.0.0.**

The repository currently publishes the complete engineering specification, package mechanics, formulas, release evidence, required QGIS projects, and do-not-regress rules. The exact source tree should be added here when the accepted release archive is uploaded directly through GitHub.
