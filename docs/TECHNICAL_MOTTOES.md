# Technical Mottoes

> **Build it online. Carry it offline.**

> **QGIS makes the pixels. The converter packs the pixels. ArcGIS Earth displays the pixels.**

> **It is not the number of bytes that matters. It is what the bytes are doing.**

These phrases summarize the project’s 2026 engineering direction: use mature systems for the heavy work, build the exact missing interoperability layer, and keep essential field operation independent of network availability.
