# Future work

Possible future work belongs after the v1.0 baseline and should not destabilize the proven release:

- additional legal/permitted source recipes;
- ArcGIS Field Maps crossover testing with Factory-made TPKX;
- public packaging / installer refinement;
- F22 -> ArcGIS Earth live-position integration;
- QR -> ArcGIS Earth Automation API commands;
- native GNSS/COM field acceptance;
- additional operator documentation and video;
- optional self-contained runtime packaging.

Any new feature should preserve the existing offline-first architecture and the normal-user simplicity of v1.0.0.
